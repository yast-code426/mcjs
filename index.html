❓ 常见问题解答

旧网站 mc.js.cool 还能用吗？
mc.js.cool 是本站很久以前的旧网站，现已停止运营，已完全迁移至 mcjs.cc。请将旧网站从收藏夹移除，更换为本站 mcjs.cc。
如果本站主页在部分地区被拦截，请使用唯一官方镜像站 MCJS.Link。
MCJS 有且只有两个官方域名：mcjs.cc 和 mcjs.link，请直接在地址栏输入，谨防搜索引擎的假冒网站。
游戏主站 play.mcjs.cc 无法访问怎么办？
由于部分用户滥用服务及恶意举报，play.mcjs.cc 被运营商 DNS 劫持。
声明：本网站是纯静态 HTML 网站，不会收集或上传任何用户信息，更不是诈骗网站！
临时解决方法：使用本镜像站提供的备用线路（点击"启动"后选择其他镜像），或使用网络代理访问主线路。
游戏存档会消失吗？
MCJS 适合临时设备快速体验 MC，受浏览器缓存限制，存档可能随时被自动删除。
建议：长期游玩请定期备份存档，或导出至正版客户端使用。
游戏打不开 / 卡死 / 崩溃怎么办？
请使用最新版 Google Chrome 浏览器访问，尽量避免使用其他浏览器。
推荐使用 WASM 版本（性能最佳）。设备建议使用性能较好的电脑，而非手机等移动设备。
多人游戏怎么联机？
MCJS 支持三种联机方式：
• 单机：单人游玩，无需网络。
• 局域网联机：同一网络下，房主开启"共享世界"，其他设备在"多人游戏"中自动发现房间。
• 远程联机（P2P + TURN 中转）：房主开启"共享世界"生成邀请码，其他设备输入邀请码直连。支持跨网络远程联机，数据通过 WSS 协议加密传输。
禁止滥用联机服务，一经发现永久拉黑来源 IP！
手机 / 平板能玩吗？
有且只有 MCJS 官方 1.8.8 版本 能在移动触屏设备上运行并适配触屏操作。
其他版本仅支持电脑端，推荐使用电脑浏览器体验。
新版本（1.16.5 / 1.21.11 / 26.1.2）稳定吗？
这些是 非常早期的测试版，不稳定且 bug 多，仅用于尝鲜体验。
高版本对设备性能要求极高，只有 WASM 版本，需要高性能电脑才能流畅运行，否则浏览器容易崩溃。
如有 bug 请勿反馈，等正式版发布后再提交。
如何反馈问题或提出建议？
MCJS 目前 有且只有 GitHub 官方支持平台，其他平台均为假冒。
请前往 MCJS 官方 GitHub Issues 提交反馈。
请先阅读常见问题，查看往期 issues，再提问！重复提问常见问题将被禁止再次提问。
